## 2. التكليفات التنفيذية حسب الجهة

### GitHub / CI
- تحقق من الفرع وSHA الحاليين، ثم استخرج الحالة النهائية للتشغيلين `43504719570` و`43504719789`، مع نتائج الوظائف والخطوات الفاشلة إن وجدت.

- لا تعتبر الفحص ناجحاً قبل ظهور `completed / success`، ولا تخلط بين build/dry-run والنشر.

### Lovable
- أعد جرد الملفات الحرجة وقارنها ملفاً بملف مع GitHub على SHA الموثق.
- جهّز قائمة فروقات وخطة مزامنة دقيقة تحفظ ملفات وإعدادات Lovable الخاصة، وتصحح Project Knowledge المتعارض مع قرارات المشروع.
- لا تنفذ استبدالاً شاملاً أو كتابة/مزامنة قد تمحو ملفات خاصة. لا تغيّر الربط أو الفرع ولا تنشر. إذا تعذر الوصول أو القراءة أو التحديث، أبلغ فوراً بالتحديد.

### Cloudflare
- افحص إعداد Worker وبيانات آخر deployment وارتباط GitHub Builds، وحدد ما يلزم لإثبات مصدر النسخة المنشورة وSHA الذي بُنيت منه.
- قدم أدلة قابلة للتحقق، لا استنتاجات من نجاح CI وحده.
- لا تنفذ deploy أو تغيّر إعدادات الإنتاج أو فرع الإنتاج. إذا كانت الصلاحية أو البيانات غير متاحة، أبلغ بذلك فوراً.

### Supabase
- استعد الوصول إلى المشروع المستهدف `jezpyxuxjzxotxjykhky` عبر الاتصال/الصلاحيات الصحيحة، ولا تستخدم أي مشروع آخر بديلاً.
- بعد توفر الوصول، نفذ جرداً وقراءة تحقق فقط لحالة المشروع وAuth وStorage وRLS والسياسات والمستشارين الأمنيين، ووثق الأدلة والفجوات.
- ممنوع تنفيذ SQL تغييري أو migrations أو تعديل schema أو سياسات أو بيانات دون موافقة صريحة منفصلة. لا تطلب أو تكشف كلمات مرور أو مفاتيح سرية في المذكرة أو السجلات.

## 4. الإبلاغ الإلزامي عن الأدوات غير المربوطة أو المتعذرة
يجب الإبلاغ فوراً إلى صاحب المشروع عند تحقق أي مما يلي:
- أداة أو خدمة غير مربوطة أصلاً، أو الاتصال بها غير متاح.
- صلاحية مفقودة أو رفض وصول مثل `permission denied`.
- فشل مصادقة أو انتهاء جلسة أو عدم توفر المورد.
- تعذر قراءة البيانات أو تنفيذ المهمة بسبب عطل تقني.

يجب أن يتضمن البلاغ: **اسم الأداة/الخدمة، المهمة المتأثرة، نص الخطأ كما ظهر دون أسرار، وقت المحاولة، ما تم التحقق منه، وما البديل الآمن المتاح**. لا تطلب من المستخدم إعادة ربط أداة إلا بعد إثبات أن الاتصال غير موجود أو يحتاج إجراءً منه، وحدد الإجراء المطلوب بدقة. إذا لم يوجد اتصال فعلي، صرّح بذلك ولا تدّعِ إرسال التكليف أو تنفيذه عبر تلك الأداة.
